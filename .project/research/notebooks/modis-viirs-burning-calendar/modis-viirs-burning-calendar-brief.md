We are currently in the ideation stage. We have thought about how the satelites work (which seems to be through Thermal Infrared Sensors) and seeing the heat signatures from generated fires. Third, for user decisions, like the questions that you have proposed. Finally, like the event context and using more information to corroborate the detection of an event.
