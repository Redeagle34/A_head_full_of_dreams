Read top-down: the root problem, its parts in priority order, then what each part still needs. Filled cards are known, dashed cards are still open.

Details

  • Regional burning calendar partly · theory: fire regime analysis
    Help users examine regional burning history and apply it to prevention, incident review, and forecasts.
  • P1 · Comparable sensor records partly · theory: measurement comparability
    Different footprint sizes and observation schedules can change detection counts. Test how well older MODIS and newer VIIRS records line up.
    • Common activity measure partly
      Which spatial and time units make hotspot activity reasonably comparable across sensors?
    • Overlap period validation partly
      How closely do sensors agree in withheld regions or seasons, and how much do observation gaps affect the result?
  • P1 · Historical activity patterns open · theory: seasonal baseline
    Explain what is typical for a place and season, and identify periods with unusually high observed activity. Needs harmonize (supports comparison) first.
    • Seasonal reference periods partly
      How can users compare recent activity with earlier years for the same season and region?
    • Unusual activity periods partly
      Which methods highlight anomalies and recurring critical windows without confusing missing observations with low activity?
  • P1 · User decisions open · theory: decision support
    Use consistent evidence to help firefighters review incidents and help land managers assess where preventive work may be warranted. Needs compare (informs decisions) first.
    • P2 · Prevention planning partly · theory: wildfire risk assessment
      Identify candidate zones for fuel treatment based on treatment suitability and expected reduction in harm. Needs context (adds burn history) first.
      • Treatment suitability partly
        Which fuel, terrain, ecological, exposure, and treatment history datasets can support expert review?
    • P2 · Incident review partly · theory: situational awareness
      Help responders review recent detections quickly and let scientists inspect the supporting observations.
      • Audience workflows open
        Which questions should each audience answer using the calendar, map, and downloadable outputs?
      • Review priorities partly
        Which evidence supports a decision to review an observation and how can uncertainty be communicated? Needs context (supports review) first.
      • Detection recency partly
        What source, observation time, confidence, and corroboration should responders and scientists see?
  • P2 · Event context partly · theory: evidence triangulation
    Assess which independent records can explain a detection or corroborate where and when an event occurred.
    • Planned burn records partly
      Where are reliable planned or completed burn records available, and how closely can they match a hotspot in place and time?
    • Airborne observations partly
      Where can the team obtain aircraft-derived infrared perimeters, and how well can they check satellite timing and extent?
    • Landsat imagery partly
      Check active-fire points and optical surface change where clear scenes are available.
    • Vegetation and fuels partly
      Check how mapped fuels support prevention and whether recent vegetation observations improve forecasts.
    • Smoke plumes partly
      Check plume context for recent events and whether smoke available at issue time adds forecast skill.
  • P2 · Future activity forecasts partly · theory: spatiotemporal forecasting
    Estimate where and when activity is more likely and test predictions on years withheld from training. Needs compare (provides baseline), vegetation (tests forecast gains), smoke (tests forecast gains) first.
    • Forecast target known
      Estimate satellite-observed burning activity during the following seven days. Grid size and reference platform remain open.
    • Forecast validation partly
      Can retrospective forecasts using only information available at the time beat the seasonal historical baseline?
